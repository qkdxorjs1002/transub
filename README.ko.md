Transub는 영상의 내장 텍스트 자막을 한국어로 번역하는 Python 명령줄 도구입니다. 기존 ChatGPT 로그인으로 Codex CLI가 작품 배경을 조사하고 대사를 번역합니다. Python 외부 패키지나 OpenAI API 키는 필요하지 않습니다.

> [!IMPORTANT]
> **기본 실행은 검증 후 원본 MKV를 교체하며, 자동 백업을 만들지 않습니다.**
> 원본을 따로 보관하려면 실행 전에 복사하거나, 단일 영상에 `-o '/path/to/output.mkv'`를 지정하세요. 폴더 입력에는 `-o`를 사용할 수 없습니다.
> 임시 리먹스용으로 원본 크기 정도의 여유 디스크 공간을 확보하세요.

## 주요 기능

- **작품 맥락을 반영한 번역:** 웹 검색으로 작품·용어·인물 관계를 조사하고 대사 전후 문맥을 함께 전달합니다.
- **자막 서식 보존:** ASS의 시간, 스타일, 레이어, 태그, 드로잉과 동시 표시 관계를 유지합니다.
- **교체 전 검증:** 자막 내용·패킷 전달 순서와 영상·음성 SHA-256 등을 검사한 뒤 파일을 교체합니다.
- **중단 후 재개:** 작품 조사와 검증된 번역 배치를 저장해 같은 작업에서 재사용합니다.
- **폴더 일괄 처리:** 모든 하위 폴더의 MKV를 찾아 순서대로 처리하고, 기존 한국어 자막이 있는 파일은 기본적으로 건너뜁니다.

신규 작업의 기본값은 **`gpt-6.1-sol` · 추론 강도 `medium`**입니다. 조사와 번역에 같은 설정을 명시해 사용하며, 모델을 사용할 수 없을 때 다른 모델로 자동 대체하지 않습니다.

## 빠른 시작

**준비물:** macOS 또는 Linux, Python 3.10 이상, FFmpeg와 FFprobe, 호환되는 Codex CLI, 파일에 저장된 ChatGPT 로그인 정보. 네트워크 연결과 Codex 사용량이 필요합니다.

1. FFmpeg와 FFprobe를 설치합니다. macOS에서 Homebrew를 사용한다면:

   ```bash
   brew install ffmpeg
   ```

   Linux에서는 배포판의 패키지 관리자로 FFmpeg와 FFprobe를 설치하세요.

2. [공식 Codex CLI 설치 안내](https://learn.chatgpt.com/docs/codex/cli)에 따라 설치한 뒤, 파일 저장 방식을 지정해 ChatGPT 계정으로 로그인합니다.

   ```bash
   codex login -c 'cli_auth_credentials_store="file"'
   ```

   Transub는 Codex 홈의 `auth.json`을 읽습니다. 키체인에만 저장된 로그인은 읽지 않으므로 파일 저장 방식이 필요합니다. 저장 방식은 [공식 인증 문서](https://learn.chatgpt.com/docs/auth)를 참고하세요.

3. 프로젝트 디렉터리에서 실행합니다.

   ```bash
   python3 transub.py '/path/to/video.mkv'
   ```

완료 후 플레이어에서 **한국어 (Codex 번역)** 트랙을 선택하세요. 이미 영상을 열어 두었다면 닫았다가 다시 열어야 교체된 파일을 읽습니다. 한국어 자막을 기본으로 선택하려면 실행할 때 `--default-korean`을 추가하세요.

Codex CLI **0.153.4에서 검증한 이력이 있습니다.** 현재 설치본에 필수 격리 기능이 없으면 실행을 중단합니다. 자세한 요구 사항은 [지원 범위와 제약](#지원-범위와-제약)을 참고하세요.

## 사용 방법

**폴더와 모든 하위 폴더의 MKV 처리**

```bash
python3 transub.py '/path/to/videos' --work-dir './work/series'
```

별도 재귀 옵션은 필요하지 않습니다. 시작할 때 `.mkv` 파일 목록을 대소문자 구분 없이 수집하고, 상대 경로순으로 정렬해 하나씩 처리합니다. 파일·폴더 심볼릭 링크와 `.transub-mux-*` 임시 디렉터리는 제외하며, 처리할 MKV가 없으면 오류로 종료합니다.

기존 한국어 자막이 있는 파일은 기본적으로 건너뜁니다. 개별 파일이 실패해도 나머지 파일은 계속 처리합니다.

**번역 전에 내장 자막 트랙 확인**

```bash
python3 transub.py '/path/to/video.mkv' --list-tracks
python3 transub.py '/path/to/videos' --list-tracks
```

`--list-tracks`는 번역이나 영상 수정 없이 트랙 번호·언어·코덱·제목을 표시합니다. 특정 트랙을 번역하려면 표시된 FFprobe 스트림 번호를 `--source-track`에 지정하세요.

**작품 힌트와 기본 한국어 자막 지정**

```bash
python3 transub.py '/path/to/video.mkv' \
  --title '작품명 시즌 / 회차' --default-korean
```

**추론 강도 변경 — 각각 새 작업 디렉터리 사용**

```bash
python3 transub.py '/path/to/video.mkv' --reasoning high --work-dir './work/high'
python3 transub.py '/path/to/video.mkv' --reasoning low --work-dir './work/low'
```

`low`, `medium`, `high`, `xhigh`를 사용할 수 있습니다. 설정별 번역 품질과 속도를 비교 측정한 결과는 없습니다.

**한국어 폰트 지정 및 첨부**

```bash
python3 transub.py '/path/to/video.mkv' --font 'Noto Sans CJK KR' \
  --font-file '/path/to/font.otf'
```

`--font`에는 폰트 파일의 내부 글꼴 이름을 지정하세요. TTF, OTF, TTC 파일을 첨부할 수 있습니다.

**별도 MKV로 저장 — MP4 등 단일 영상에도 사용**

```bash
python3 transub.py '/path/to/video.mp4' -o '/path/to/output.mkv'
```

출력 경로는 아직 존재하지 않는 `.mkv`여야 합니다. 폴더 입력에는 `-o`를 사용할 수 없습니다.

## 옵션

| 옵션 | 용도와 기본값 |
|---|---|
| `video` | 필수 입력: 단일 영상 또는 MKV가 있는 폴더. |
| `-o`, `--output` | 단일 영상의 별도 `.mkv` 출력. 생략하면 원본 MKV 교체. |
| `--work-dir` | 진행 데이터 위치. 기본값은 실행 디렉터리의 `.transub/<파일명-경로해시>/`. |
| `--list-tracks` | 내장 자막 목록만 표시. 기본값: 사용 안 함. |
| `--title` | 작품·시즌·회차 힌트. 생략하면 파일명과 자막으로 조사. |
| `--source-track` | FFprobe 자막 스트림 번호. 기본 선택: 일본어 → 영어 → 기타 언어. |
| `--model` | 조사·번역 모델. 기본값: `gpt-6.1-sol`. |
| `--reasoning` | `low`, `medium`, `high`, `xhigh`. 신규 작업은 `medium`, 재개 시 생략하면 저장값 유지. |
| `--font` | 한국어 ASS 스타일의 글꼴 이름 변경. 생략하면 원본 유지. |
| `--font-file` | MKV에 추가할 TTF·OTF·TTC 폰트. 기본값: 추가 안 함. |
| `--default-korean` | 한국어를 기본 자막으로 지정. 생략하면 기존 기본 자막 설정 유지. |
| `--allow-existing-korean` | 한국어가 있어도 새 트랙 추가. 기본값: 단일 영상은 오류, 폴더에서는 건너뜀. |

## 재개와 출력

실패하거나 중단한 뒤에는 **같은 실행 디렉터리에서 같은 명령**을 다시 실행하세요. 저장된 작품 조사와 검증된 번역 배치를 재사용하며, 문맥이나 체크포인트 키가 달라진 배치는 다시 번역합니다. 기본 설정의 폴더 실행에서는 이미 한국어가 추가된 파일을 건너뜁니다.

`--reasoning`을 생략하면 기존 작업에 저장된 값을 유지합니다. 예전 작업에서 추론 강도를 따로 지정하지 않았다면 Codex 기본값을 따르는 기존 방식을 유지합니다. 원본이나 모델·추론 강도·소스 트랙·작품 힌트·배치 크기를 바꾸려면 새 `--work-dir`을 지정하세요.

단일 영상에서 `--work-dir`은 그 영상의 정확한 작업 디렉터리입니다. 폴더 입력에서는 그 아래에 파일별 `<파일명-경로해시>/`를 만들어, 다른 하위 폴더의 같은 이름도 구분합니다. 지정하지 않으면 실행 디렉터리의 `.transub/` 아래에 파일별로 저장합니다.

| 저장 파일 | 내용 |
|---|---|
| `source.ass`, `korean.ass` | 추출한 원문과 한국어 자막 |
| `research.json` | 작품 배경, 용어, 말투 지침과 출처 |
| `batch-*.json` | 검증된 번역 배치 체크포인트 |
| `codex-audit.json` | 호출 종류, 사용량, 소요 시간과 격리 확인 정보 |
| `verification.json` | 완료 상태와 자막·미디어 검증 결과 |

폴더 실행은 마지막에 다음과 같이 요약합니다.

```text
처리 완료: 총 12개 · 완료 11개 · 건너뜀 1개 · 실패 0개
```

실패가 있으면 상대 경로·이유와 재실행 안내를 덧붙입니다. 종료 코드는 실패 없음 **`0`**(건너뜀 포함), 한 건 이상 실패 **`1`**, Ctrl+C 중단 **`130`**입니다. 진행 데이터와 보고서는 JSON 파일로 남습니다.

## 지원 범위와 제약

| 항목 | 지원 범위 |
|---|---|
| 영상 입력 | 단일 MKV 또는 폴더의 MKV. MP4 등 다른 단일 영상은 `-o`로 MKV 출력 필요. |
| 자막 입력 | 내장 ASS, SSA, SRT, WebVTT, `mov_text`, `text`. ASS 외 형식은 FFmpeg로 ASS 변환. |
| 지원하지 않는 방식 | PGS·VobSub 이미지 자막, 번인 자막, OCR, 음성 인식. |
| 소스 자동 선택 | 일본어 → 영어 → 기타 언어. 한국어는 제외하며, 전체 대사 트랙을 우선. |
| 기존 콘텐츠 | 영상·음성, 기존 자막, 챕터와 첨부파일 보존. |
| 번역 검토 | 의미, 화자, 존댓말과 말투는 사람이 확인해야 함. |

언어 표기가 없거나 잘못된 트랙은 `--source-track`으로 직접 선택하세요. 원본의 동시 표시와 배치는 유지하므로, 원래부터 겹쳐 읽기 어려운 자막을 자동 재배치하지 않습니다. ASS 인라인 `\fn` 태그와 카라오케 타이밍도 유지되어, 글꼴이 한국어를 지원하지 않거나 음절 타이밍이 맞지 않을 수 있습니다.

Codex CLI에는 `--ignore-user-config`, `--ignore-rules`, `--ephemeral`, `--output-schema`, `skip_host_skill_discovery`가 필요합니다. 호환되지 않으면 중단하며, 실험 기능이 포함되어 있어 CLI 업그레이드 후 호환성을 다시 확인해야 합니다. 옵션 설명은 [공식 CLI 참조](https://learn.chatgpt.com/docs/cli/reference)를 참고하세요.

## 개인정보와 검증

**자막 텍스트, 파일명과 작품 힌트는 Codex에 전달되며, 영상 파일은 로컬에서 처리합니다.** 작품 조사에는 웹 검색을 사용하고 번역 단계에서는 웹 검색을 끕니다. 로컬 진행 데이터에도 원문·번역 자막과 조사 결과가 저장됩니다.

Transub는 비공개 임시 `CODEX_HOME`에 인증 파일만 권한 `0600`으로 복사합니다. 개인 설정·MCP·규칙·스킬·플러그인·세션은 복사하지 않으며, 시스템·조직 관리 정책은 계속 적용됩니다. 임시 홈은 작업 종료 시 삭제하고, 갱신된 인증 정보는 원래 Codex 홈에 다시 쓰지 않습니다.

원본은 자막과 미디어 검증을 통과한 뒤 원자적으로 교체합니다. 교체 전 실패하면 원본을 유지하지만 자동 백업은 만들지 않습니다. 처리 중 외부 편집기로 같은 원본을 수정하지 마세요.

<details>
<summary>격리 및 미디어 검증의 상세 동작</summary>

- 자식 프로세스 환경은 허용 목록으로 구성하며, 상위 세션의 API 키·provider URL 설정을 전달하지 않습니다. 읽기 전용 샌드박스를 사용하고 시작 시 MCP 목록이 비어 있는지 확인합니다. MCP·셸 호출이 발견되면 실패하며, 작품 조사에는 실제 웹 검색 사용 기록이 있어야 합니다.
- 원본 ASS의 이벤트·텍스트 구간 ID를 검사하고 서식·드로잉을 보존합니다. 결과에서 한국어 자막을 다시 추출해 모든 이벤트 필드를 비교합니다.
- 실제 패킷 읽기 순서를 검사해 자막이 해당 장면보다 늦게 전달되지 않는지 확인합니다. 영상·음성 데이터와 첨부파일의 SHA-256, 첨부파일 메타데이터도 비교합니다.
- 원본 파일과 작업 디렉터리 잠금으로 Transub 간 동시 수정을 차단하고 교체 직전 파일 변경을 재확인합니다. 인증 값과 CLI 원시 stderr는 결과물에 저장하지 않습니다.
- Matroska 리먹스에서 HEVC `hvcC`의 `array_completeness` 비트가 `1`에서 `0`으로 바뀐 경우만 엄격한 검사 후 허용합니다. 구조와 크기가 같고 다른 바이트 변경이 없어야 하며, 다른 스트림 특성 변경과 영상·음성 해시 불일치는 실패로 처리합니다.
- `max_interleave_delta=0`으로 자막 전달 순서를 유지합니다. 자막 간격이 길면 FFmpeg의 버퍼 메모리 사용이 늘어날 수 있습니다.

</details>

## 문제 해결

| 증상 | 확인할 사항 |
|---|---|
| `auth.json`을 찾지 못함 | 빠른 시작의 파일 저장 로그인 명령을 실행하거나 `--auth-home`으로 기존 홈 지정. |
| 로그인 만료·갱신 오류 | 원래 Codex 홈에 다시 로그인한 뒤 같은 작업 재개. 임시 홈의 갱신 정보는 원래 홈에 반영되지 않음. |
| 필수 격리 옵션·호스트 스킬 차단 미지원 | 필요한 기능이 있는 Codex CLI로 업데이트. |
| 모델 접근 오류 | 계정에서 선택한 모델을 사용할 수 있는지 확인. 모델을 바꾸면 새 작업 디렉터리 사용. |
| 이미 한국어 자막이 있음 | 기존 트랙을 확인. 새 트랙을 추가하려는 경우에만 `--allow-existing-korean` 사용. |
| 지원하는 텍스트 자막 트랙이 없음 | 지원 형식의 내장 텍스트 자막이 있는 영상 사용. 이미지 자막이나 음성은 변환하지 않음. |
| 기존 작업의 원본·설정이 다름 | 기존 체크포인트를 유지하고 새 `--work-dir` 지정. |
| 한글이 네모로 보임 | 한국어 지원 폰트와 `--font`·`--font-file` 확인. 인라인 글꼴 태그는 보존됨. |
| 스트림 검증 실패 | 출력된 변경 항목 확인. 교체 전 원본은 유지되므로 원인 해결 후 같은 명령으로 재개. |
| 새 자막이 보이지 않음 | 영상을 다시 열고 한국어 트랙 선택. |
| 디스크 공간 부족 | 원본 크기 정도의 임시 여유 공간 확보 후 재개. |

## 개발

프로젝트 디렉터리에서 회귀 테스트를 실행합니다.

```bash
python3 -m unittest discover -s tests -v
```

테스트는 작은 합성 영상을 실제 FFmpeg로 생성·리먹스하고 Codex 응답을 모의 처리합니다. 원본 교체, 영상·음성 보존, 자막 중첩, 실패 시 원본 유지와 재개 동작을 검증합니다. 실행에는 FFmpeg와 FFprobe가 필요하며, 실제 Codex 번역 세션이나 번역 품질 측정은 포함하지 않습니다.
